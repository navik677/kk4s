# kk4s — Kirikiri for Switch

Homebrew-рушій для Nintendo Switch, який запускає візуальні новели на **Kirikiri2 / KAG** без жодних змін файлів гри. Кидаєш папку гри на SD-карту, вибираєш її в лаунчері — і граєш. Той самий рушій працює і на ПК (Linux, Windows) як PC viewer.

В основі — рушій [krkrs](https://github.com/uyjulian/krkrs) (порт Kirikiri на SDL2) з виправленнями для Switch і сумісністю з папками, підготовленими для Kirikiroid2 (Android).

## Можливості

- **Ігри як є.** Підтримуються зашифровані архіви через `xp3filter.tjs` (як у Kirikiroid2), `Override2.tjs` / `AfterInit2.tjs`, заміни популярних Windows-плагінів (`util.dll`, `filter.dll`, `extrans.dll`, …).
- **Лаунчер з обкладинками.** Карусель або сітка, розмите тло з обкладинки, історія запусків, годинник і батарея.
- **Обкладинки з інтернету.** Пошук у базі [VNDB](https://vndb.org) прямо з лаунчера, по одній грі або для всіх одразу.
- **Меню в грі** (кнопка **+** або **−**): швидке збереження і завантаження, гучність, керування, вихід у лаунчер.
- **Збереження окремо від гри.** Усі сейви лежать у `kk4s/saves/`, а папка гри не змінюється. Є резервні копії, відновлення і видалення.
- **Налаштовуване керування.** Для кожної кнопки геймпада можна вибрати дію; сенсорний екран працює як миша.
- **4 мови інтерфейсу:** українська, англійська, російська, японська.
- **Кирилиця в японських шрифтах.** Якщо шрифт гри малює кирилицю «на всю ширину», літери підставляються з пропорційного шрифту — для фанатських перекладів.

## Встановлення на Switch

1. Скачай `kk4s.nro` з [nightly-релізу](https://github.com/navik677/kk4s/releases/tag/nightly).
2. Поклади на SD-карту:
   ```
   sdmc:/switch/kk4s/kk4s.nro
   sdmc:/switch/kk4s/games/<НазваГри>/    ← вміст папки гри як є (data.xp3, patch.xp3, …)
   ```
3. Запусти kk4s з hbmenu **в режимі title takeover** (тримай R під час запуску будь-якої гри), а не з альбому: в альбомі дуже мало пам'яті.

Гра розпізнається, якщо в папці є `startup.tjs` або хоча б один `*.xp3`.

## Керування

**Лаунчер**

| Кнопка | Дія |
|---|---|
| Хрестовина / лівий стік / свайп | вибір гри |
| A / тап по вибраній картці | грати |
| Y | обкладинка з інтернету |
| − | опції гри (обкладинка, збереження) |
| X / шестерня | налаштування |
| L / R | гортати на 5 ігор |
| + | вихід з kk4s |

**У грі** (стандартна розкладка; змінюється в налаштуваннях → «Керування»)

| Кнопка | Дія |
|---|---|
| A | далі (Enter) |
| B | меню гри / сховати текст (правий клік) |
| X, ZR (тримати) | пропуск тексту (Ctrl) |
| Y | пробіл |
| L / R | історія (Page Up) / Page Down |
| ZL | Shift |
| Хрестовина / лівий стік | вибір пунктів (стрілки) |
| + / − | меню kk4s |
| Сенсорний екран | миша (тап = клік) |

Коли гра закривається, kk4s повертається в лаунчер (це можна вимкнути в налаштуваннях).

## Папки на SD-карті

```
sdmc:/switch/kk4s/
├── games/<Гра>/        ігри (не змінюються)
├── saves/<Гра>/        збереження; резервні копії — у saves/.backup/
├── covers/<Гра>.jpg    обкладинки (завантажені або свої)
├── logs/               лог кожного запуску
├── settings.ini        налаштування та історія запусків
└── fonts/              додаткові шрифти
```

Свою обкладинку можна покласти як `covers/<НазваПапки>.jpg` (також png або webp), а свою назву гри — першим рядком у `games/<Гра>/title.txt`. Докладніше — у [docs/launcher.md](docs/launcher.md) і [docs/sd-layout.md](docs/sd-layout.md).

Якщо гра не запускається, лог у `sdmc:/switch/kk4s/logs/` зазвичай показує причину: помилку скрипту, плагін, якого бракує, або відсутній шрифт.

## PC viewer

`kk4s <папка гри>` — запустити гру напряму; просто `kk4s` — відкрити лаунчер з іграми з `games/` поруч з програмою (або з `$KK4S_ROOT/games`). Меню в грі — F1. Деталі: [docs/pc-viewer.md](docs/pc-viewer.md).

## Збірка

Кожен push у `main` збирається в GitHub Actions; `.nro` і `.elf` з'являються в артефактах і в релізі `nightly`.

Локально:
```bash
# Switch, через Docker
docker build -t kk4s-build .
docker run --rm -v "$PWD":/src kk4s-build bash tools/build-switch.sh    # → out/kk4s.nro

# Switch, зі встановленим devkitPro
bash tools/build-switch.sh

# PC viewer (Linux / Windows MSYS2)
DEPS=1 bash tools/build-desktop.sh                                       # → out-desktop/kk4s
```

## Структура

| Папка | Що там |
|---|---|
| `engine/` | рушій krkrs; наші правки позначені коментарем `kk4s:` (`git grep kk4s: engine/`) |
| `compat/` | сумісність з Kirikiroid2, заміни плагінів, шрифти, перенаправлення збережень |
| `platform/common/` | лаунчер, меню в грі, малювання інтерфейсу, переклади, налаштування, VNDB, логер |
| `platform/switch/`, `platform/desktop/` | платформна частина: libnx / ПК |
| `tests/` | синтетичні тестові «ігри» (без контенту реальних ігор) |
| `tools/` | скрипти збірки, розбір краш-репортів, `xp3ls` |
| `docs/` | документація (англійською) |

## Правила проєкту

- Файли гри ніколи не змінюються. Виправлення — тільки в коді рушія, у `compat/` або в окремих файлах kk4s.
- У репозиторії немає ассетів, тексту і ключів шифрування реальних ігор.
- Ліцензії: [THIRD_PARTY.md](THIRD_PARTY.md); рушій — `engine/LICENSE` (Kirikiri, BSD-подібна). Обкладинки завантажуються з VNDB у момент використання і в репозиторій не потрапляють.
